# Release 1.6.0 (versionCode 8)

Upload `Dragon-Slots-1.6.0-vc8-release.aab` to the Play Console. Upload `mapping-vc8.txt` if the console does not import the embedded R8 mapping automatically. `upload-certificate.pem` is the public certificate for initial Play App Signing / upload-key registration.

The bundle was produced by the release build with R8 enabled and verified as JAR-signed. File hashes are recorded in `SHA256SUMS.txt`.
