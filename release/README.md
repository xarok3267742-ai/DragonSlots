# Release 1.6.4 (versionCode 12)

Upload `Dragon-Slots-1.6.4-vc12-release.aab` to the Play Console. Upload `mapping-vc12.txt` if the console does not import the embedded R8 mapping automatically. `upload-certificate.pem` is the public certificate for Play App Signing / upload-key registration.

This build includes the new v6 dragon-gentleman launcher icon, while retaining
the corrected COST/SCORE layout and high-contrast coin balance from 1.6.3.

The bundle was produced by the release build with R8 enabled and verified as JAR-signed. File hashes are recorded in `SHA256SUMS.txt`.
