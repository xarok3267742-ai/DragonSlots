# Release 1.6.3 (versionCode 11)

Upload `Dragon-Slots-1.6.3-vc11-release.aab` to the Play Console. Upload `mapping-vc11.txt` if the console does not import the embedded R8 mapping automatically. `upload-certificate.pem` is the public certificate for Play App Signing / upload-key registration.

The corrective build centers short values inside the separate `COST` and `SCORE`
panels. The top balance is wider and uses larger bold gold text with a dark outline
and shadow, keeping the total readable over every slot theme.

The bundle was produced by the release build with R8 enabled and verified as JAR-signed. File hashes are recorded in `SHA256SUMS.txt`.
