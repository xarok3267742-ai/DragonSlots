# Dragon Slots

Signed Google Play release artifacts for Dragon Slots.

## Current release

- Package: `com.dragonslots`
- Version: `1.6.1`
- Version code: `9`
- Bundle: [`release/Dragon-Slots-1.6.1-vc9-release.aab`](release/Dragon-Slots-1.6.1-vc9-release.aab)

This corrective release uses neutral player-facing terminology (`COST`, `SCORE`,
`REWARDS`, and `NO MATCH`) and fixes the compact gameplay meter layout.

The `release/` folder also contains the R8 mapping file, public upload certificate, and SHA-256 checksums. Private signing keys and passwords are intentionally not included.
